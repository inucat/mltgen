# mltgen

VOICEVOXなどで生成したLABファイルから、Kdenliveなどの動画編集ソフト用のMLTファイルを生成するツールです。

主な用途は、口パク用の立ち絵画像を音素ごとに切り替えるアニメーションの自動生成です。

## 特徴

- LABファイルを読み込んでMLTを生成
- 音素ごとの画像切り替え
- ランダムな瞬き
- 1段階・2段階瞬きに対応
- 音素一覧表示
- 画像が定義されていない音素はデフォルト画像へフォールバック
- LAB 終了後も指定時間までアニメーションを継続可能

## 動作環境

Python 3.12 以降推奨

## 使用ライブラリ:

- argparse
- dataclasses
- pathlib
- random
- xml.etree.ElementTree

すべて標準ライブラリのみです。

## LABファイル形式

各行に下記要素が空白区切りで記述されている想定です。
時刻単位はVOICEVOXが出力する100ns（百ナノ秒）単位です。

```
開始時刻 終了時刻 音素
```

例:

```
0 9493333 pau
9493333 10026667 n
10026667 12800000 a
```

## 画像ファイルの配置

キャラクターごとにフォルダを作成し、その中へ画像を配置します。

例:

```
character/

    a.png
    i.png
    u.png
    e.png
    o.png

    n.png

    x.png
```

### デフォルト画像

画像が存在しない音素には `x.png` が使用されます。
そのため最低限 `x.png` は用意してください。

### 瞬き

#### 1段階瞬き

各音素の末尾に `-b` または `-b1` を付したファイルを用意します。

例:

```
a.png
a-b.png
```

次のように画像が切り替わります:

```
a
↓
a-b
↓
a
```

#### 2段階瞬き

1段階瞬き用に加えて、2段階瞬き用に `-bb` または `-b2` を付したファイルを用意します。

例:

```
a.png
a-b.png
a-bb.png
```

または

```
a.png
a-b1.png
a-b2.png
```

次のように画像が切り替わります:

```
a
↓
a-b
↓
a-bb
↓
a
```

## 実行方法

```
python mltgen.py sample.lab --dir ./character
```

実行すると `{{LABファイル名}}.mlt` が生成されます。

## コマンドラインオプション

### --dir

画像フォルダを指定します。
下記 --list-sounds を指定しない場合は **必須** です。

例:

```
--dir ./character
```

### --fps

> ![NOTE]
>
> 動画編集ソフトで指定したFPSと異なる値でMLTファイルを生成すると、口パクのずれが生じるおそれがあります。

> ![WARNING]
>
> 整数のみ対応です。

動画のフレームレートを指定します。

既定値: 30

### --last

アニメーション終了時刻を指定します。
**秒数** または **mm:ss形式** で指定できます。

LABの終了時刻より長い場合は「無発声状態＋瞬きのみ」を継続します。

### --seed

瞬きタイミングの乱数シードを固定します。
同じシード値を使用すると、毎回同じ瞬きタイミングになります。

### --list-sounds

LABファイル中に出現する音素一覧を表示します。
MLTファイルは生成されません。

例:

```
python mltgen.py sample.lab --list-sounds
```

## 瞬きタイミング

瞬きはランダムに発生します。
現在は平均約6秒間隔の正規分布ベースで生成されます。

## 既知の制限

- 大文字音素（Nなど）は未対応
